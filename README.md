# Solved Programming Problems

This repository serves as a comprehensive collection of solutions for various competitive programming problems across multiple Online Judges (OJs). It reflects my journey in algorithmic problem solving, featuring optimized solutions and structured implementations.

## 🚀 Overview

The repository includes solutions for over **450 problems** from platforms such as **Codeforces**, **LeetCode**, and others. These solutions cover a wide range of topics, from fundamental data structures to advanced algorithmic techniques.

## 📊 Statistics & Platforms

- **Total Solved:** 450+ Problems
- **Platforms Included:**
    - Codeforces
    - LeetCode
    - Vjudge / UVa
    - LightOJ
- **Primary Languages:** C++, Python

## 🛠 Tech Stack & Topics

The solutions implementation focuses on:
- **Data Structures:** Trees, Graphs, Hash Maps, Heaps, Disjoint Set Union (DSU).
- **Algorithms:** Dynamic Programming (DP), Greedy, Breadth-First Search (BFS), Depth-First Search (DFS), Backtracking, and Two Pointers.
- **Complexity:** Focus on optimal time and space complexity suitable for competitive environments.
